# CivicPulse AI Frontend

The root `index.html` is currently the polished standalone demo.

This folder is reserved for the production frontend migration. The first target can be either:

- Vanilla modular frontend using `src/lib/api.js` and `src/lib/demoData.js`
- React/Next.js if the hackathon build phase requires a framework

Keep the visible demo flow focused:

1. Citizen complaint portal
2. AI analysis result
3. Authority dashboard
4. Contractor offer dispatch
5. Citizen tracking
